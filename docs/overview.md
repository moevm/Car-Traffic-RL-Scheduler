# Ход обучения

## Формирование обучающей среды

Перед обучением [TrafficScheduler.learn()](../src/facade/facade.py) запускает __setup_start_simulation_state(): создаётся начальное состояние SUMO, генерируется начальный трафик, оставшиеся светофорные объекты группируются, после чего сохраняются группы, remain_tls и параметры дорожной сети. При new_checkpoint=true начальное состояние SUMO сохраняется в checkpoint.

Net.make_traffic_lights_groups() выполняет иерархическую кластеризацию с использованием k-medoids. В результате формируются группы по четыре светофорных объекта. Объекты, не вошедшие в группы, помещаются в remain_tls и не управляются агентом.

## Алгоритм обучения

Используется MaskableRecurrentPPO. Подробнее [тут](https://sb3-contrib.readthedocs.io/en/master/modules/ppo_mask.html)

### Сбор данных и обновление модели

[MaskableRecurrentPPO.collect_rollouts()](../src/facade/learning_algorithm/maskable_recurrent_ppo.py) на каждом шаге преобразует текущее observation и action_mask в tensor и передаёт их политике вместе с текущим LSTM-состоянием и episode_starts. Политика возвращает action, value, log_prob и новое LSTM-состояние, после чего выполняется env.step(action). В MaskableRecurrentDictRolloutBuffer добавляются предыдущее observation, действие, reward, episode_start, значение функции состояния, log_prob, предыдущее LSTM-состояние и action_mask. После накопления n_steps переходов вызывается compute_returns_and_advantage(), которая рассчитывает returns и advantages. Затем train() использует данные buffer для обновления политики: вычисляются policy loss, value loss и entropy loss, после чего выполняется оптимизация с ограничением нормы градиента max_grad_norm.

### Награда

В [TrafficLightsDynamicEnv.step()](../src/facade/environment/traffic_lights_dynamic_env.py) для текущей группы вычисляются две компоненты награды step_capacity и waiting_reward. waiting_reward равен отрицательной сумме traci.lane.getWaitingTime() (время ожидания) по полосам, контролируемым светофорами текущей группы. step_capacity рассчитывается методом __calculate_step_capacity() на основе сравнения автомобилей на контролируемых полосах до и после обработки текущей группы. Итоговая награда вычисляется как step_capacity + waiting_reward.

## Завершение обучения

После завершения обучения модель trained_model и состояние VecNormalize сохраняются в vec_normalized.pkl.

# Observation & action space

## Структура observation space

Observation space формируется в классе [TrafficLightsDynamicEnv](../src/facade/environment/traffic_lights_dynamic_env.py) для каждой светофорной группы из 4 светофоров и передается вместе с наградой из метода step() вышеупомянутого класса. Состоит из следующих элементов:
| Ключ                  | Значение
| --------------------- | ------------------
| density               | Двумерный массив: [количество_светофоров][количество_полос], содержащий заполенность каждой полосы каждого светофора группы
| waiting               | Двумерный массив: [количество_светофоров][количество_полос], содержащий нормализованное количество остановившихся автомобилей на каждой полосе каждого светофора группы
| phase                 | Одномерный массив: [количество_светофоров], содержащий номер текущей фазы каждого светофора группы
| time                  | Одномерный массив: [количество_светофоров], содержащий время, прошедшее с начала текущей фазы каждого светофора
| bounds                | Одномерный массив: [количество_светофоров], содержащий границу временного состояния текущей фазы: 0 -- менее 15 секунд, 1 -- от 15 до 60 секунд, 2 -- более 60 секунд
| accumulated_capacity  | Одномерный массив: [количество_светофоров], содержащий накопленное количество автомобилей, пропущенных каждым светофором с начала текущей фазы каждого из светофоров
| mean_distance         | Двумерный массив: [количество_светофоров][количество_полос], содержащий среднее расстояние автомобилей до соответствующего светофора на каждой контролируемой полосе
| std_distance          | Двумерный массив: [количество_светофоров][количество_полос], содержащий среднеквадратическое отклонение расстояния автомобилей до соответствующего светофора на каждой контролируемой полосе
| mean_speed            | Двумерный массив: [количество_светофоров][количество_полос], содержащий среднюю скорость автомобилей на каждой контролируемой полосе
| std_speed             | Двумерный массив: [количество_светофоров][количество_полос], содержащий среднеквадратическое отклонение скорости автомобилей на каждой контролируемой полосе

## Структура action space

Пространство действий задано как вектор из четырёх элементов, каждый элемент соответствует светофорному объекту текущей группы, где: 0 -- сохранить текущую фазу, 1 -- перейти к следующей фазе.

В методе [TrafficLightsDynamicEnv.__change_phase()](../src/facade/environment/traffic_lights_dynamic_env.py) в режиме обучения (__train_mode=True) для текущей не желтой фазы при action[i]=1 вызывается traci.trafficlight.setPhase(tls_id, (current_phase + 1) % n_phases), а при action[i]=0 текущая фаза сохраняется. Если текущее состояние фазы содержит жёлтый сигнал ('y'), переключение через данный механизм не выполняется.

Отдельно от action_space метод [TrafficLightsDynamicEnv.get_action_mask()](../src/facade/environment/traffic_lights_dynamic_env.py)  формирует для каждого светофорного объекта маску на основе времени текущей фазы: при spent_duration < 15 секунд устанавливается 0, при 15 <= spent_duration <= 60 секунд -- 1, при spent_duration > 60 секунд -- 2.

В [MaskableRecurrentActorCriticPolicy._get_action_dist_from_latent_maskable()](../src/facade/learning_algorithm/policy.py) значение 0 заменяется на -1e9, а 2 -- на +1e9, значение 1 оставляет без изменения. Таким образом, если текущая фаза длится менее 15 секунд, то она не изменится, а если больше 60 -- будет изменена.
